# Logo Maker — Offline SVG Generator

A simple logo maker built for mobile. Designed and tested with **Android tablets** in mind.

## Easiest way to use it (no download at all)

Open this link in your tablet's browser:

**https://ilostmyshipsname-design.github.io/svg-offline-logo-generator/**

That's it. Type your name, tap **New design!** until you like what you see, then tap **Save my logo** (SVG file) or **Save as picture** (PNG, for social media uploads).

## Works without internet

1. On the GitHub file page, tap **index.html**, then tap the **download/raw** button to save the file to your tablet.
2. Open your **Files** app, find `index.html` in Downloads, tap it and choose **Chrome** (or any browser).
3. It runs entirely offline from then on — no internet needed.

## Notes

- Everything happens on your device. Nothing is uploaded.
- Spacebar also rolls a new design (when the text box isn't selected).
- "Want more control?" opens shape, icon, and color options.
- SVG files are the high-quality logos — use them for anything. PNG files are easiest to upload as profile pictures.
